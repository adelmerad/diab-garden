# Diab-Garden 🌱

## Installation Guide

### Prerequisites

- Node.js (v16+)
- npm or yarn
- Expo Go app on mobile

### Quick Setup

# Clone the repository

`git clone https://github.com/adelmerad/diab-garden`
`cd diab-garden`

# Install dependencies

cd frontend
npm install

# Start the app

`npx expo start`

# Known Issues

- No Cloud Storage / Profiles
- No Authentication
- Small Amount of goals/achievements
- Small amount of plants available
- Some features may have not been tested
